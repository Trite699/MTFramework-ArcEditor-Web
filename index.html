Rebuilding keeps the original (often compressed) bytes of untouched files as-is, and stores newly added files uncompressed. Empty folders exist only in this editor and are not written to the archive, since the format has no folder entries. When re-encrypting as ARCC, the same key used to load the archive (or the default) is applied. Each open tab is rebuilt and saved independently.
